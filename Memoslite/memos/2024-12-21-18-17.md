删除hnaps的方法，可以做到全局60，90，120，提前是在设置里先选60，90，120再操作下面的：

9.0如下：

删除hnaps方法。

adb shell service call package 136 s16 com.hihonor.android.hnaps i32 0 i32 0 删除指令 删除重启成功

adb shell service call package 136 s16 com.hihonor.android.hnaps i32 1 i32 0

恢复指令

8.0如下：

删除hnaps方法。

adb shell service call package 132 s16 com.hihonor.android.hnaps i32 0 i32 0 删除指令 删除重启成功

adb shell service call package 132 s16 com.hihonor.android.hnaps i32 1 i32 0

恢复指令

7.1的版本如下：

adb shell service call package 131 s16 com.hihonor.android.hnaps i32 0 i32 0 删除指令 删除重启成功

恢复指令adb shell service call package 131 s16 com.hihonor.android.hnaps i32 1 i32 0

已经在187版本测试删除成功和恢复成功！

以上是电脑上操作的代码

用黑阈的酷友：自行去掉 adb shell，黑阈是不需要这的。

操作完请自行到设置-应用-应用管理 查看是否存在hnaps，如果不存在了就是成功了，重启就好；恢复也是同理。
