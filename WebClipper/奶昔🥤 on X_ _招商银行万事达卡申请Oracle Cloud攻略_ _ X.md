0）开卡


========

最近大家都在申请招商银行的万事达借记卡，里面放人民币就能自动购汇，不占用每年5w美元便利化额度。以普卡为例，具体参数如下：

1）准备钱钱


==========

说回正题，由于甲骨文存在预授权冻结，粗略计算总成本会高达140SGD（约750人民币，取决于汇率）。尤其是升级账户时，会预授权100美元等值货币，特别是在升级前的免费账户阶段一旦预授权失败将导致账户直接封禁。

由于该卡为借记卡（Debit）并没有信用额度，因此需要先准备760人民币（保险起见可以存800块）进去，以防扣款之需要。

[

![](https://pbs.twimg.com/media/HEjCHMyaoAA1ybX?format=jpg&name=small)

2）准备资料


==========

在注册甲骨文时需要填写个人信息，例如姓名和地址。只有招行信用卡可以直接从账单上抄标准地址，而借记卡需要通过招商银行App开立账户证明获取自己在银行预留信息。

打开你的招商银行App，进入主界面并登录后，在主页的搜索框搜索账户证明，点击带图标的这个功能选项卡

[

![](https://pbs.twimg.com/media/HEjDQBSbAAAiUwV?format=png&name=small)






](/realNyarime/article/2038116106217705668/media/2038093511376175104)

进入页面后，选择下面的信息：

*   预留手机
    
*   家庭地址
    
*   勾选需要开立的万事达卡
    

[

![](https://pbs.twimg.com/media/HEjDYlFbcAEHeuH?format=jpg&name=medium)






](/realNyarime/article/2038116106217705668/media/2038093658424307713)

然后点击同意协议提交，成功后就会发送到你预留的邮箱地址。

此时再点击下方的申请记录，即可找到申请明细，在其中找到解压密码后解压，你会得到一个PDF文件，文件有招商银行的LOGO和你的预留地址，此时我们只需要预留地址。

3）开始注册


==========

这里其实也存在部分玄学，家宽没开VPN，用的谷歌Chrome浏览器无痕模式、163邮箱也能过。不过建议是避免使用中国移动，移动出了名的墙中墙可能会污染Oracle Cloud域名，可以换中国联通、中国电信的网络申请。

填写上一步获取的资料，例如李华（名字Hua姓氏Li），电子邮件输入自己的邮箱，并完成hCaptcha下一步。

![](https://pbs.twimg.com/media/HEjEMZgaQAASDdo?format=png&name=small)

这一步过去后，不出意外就会到下一步填写密码和用户名，按照图片上填写完成即可。 此处建议优先注册地区为美西，三网虽然不极致，但是稳定还是稳定的。

![](https://pbs.twimg.com/media/HEjErMFakAAAkC3?format=jpg&name=medium)

主区域反正首尔是几乎开不出来的，东京可以试试水。求稳的话直接凤凰城或者圣何塞，总之韩国首尔和日本东京可以后续升级账户跨区开，能在CN用的爽的也就这几个地方了：

下一步很重要，这里要求你输入你的地址，必须 1:1 翻译成纯拼音，请按照下图的格式填写你的预留地址，保持中文的地址语序习惯（如：xx省 xx市 xx区 xx路），千万不要自作聪明换成西方式的英文倒序地址！

![](https://pbs.twimg.com/media/HEjFhZebMAAgEGl?format=jpg&name=900x900)

这一步填写没问题的话，就可以进入简单的验卡环节。

4）扣卡环节


==========

点击 Credit Card 部分，进入填写卡号三要素的地方，按照自己卡背面的信息填入即可。

> 请一定确保自己的卡片网付功能打开，限额调整正确！ 检查步骤：  检查网付：首页 → 银行卡 → 万事达卡 → 更多功能 → 免密/自动扣款 → 万事达卡跨境线上支付  检查限额：……同上 → 更多功能 → ATM/POS设置 → ATM/POS限额

不出意外的话，招行App的通知马上就到，扣款出现后，就直接成功，显示一个绿色的Thank You! 界面。

[

![](https://pbs.twimg.com/media/HEjF-76bMAAhK-G?format=jpg&name=900x900)






](/realNyarime/article/2038116106217705668/media/2038096516410454016)

家人们，快胜利了。激动的心，颤抖的手，这一步成败在此一举！ 请深吸一口气，勾选下方的勾选框，直接用力点击 开始我的免费试用！

5）开奖环节


==========

1、Bad


---------

先说坏结局，你看到了你最熟悉的 ABC界面：

> 处理交易时出错 无法完成您的注册。常见注册错误有： (a) 使用的是预付卡。Oracle 仅接受信用卡和借记卡； (b) 有意或无意遮挡了人员地点或身份信息； (c) 输入的账户信息不完整或不准确。如果您出现了上述情况，请重试。否则，请联系 Oracle 客户服务.

不要气馁，龟龟永远不会放弃你，此时一定不要重开注册了，请务必间隔3~7天后再次尝试，太频繁容易被干

如果登录成功后，看到顶部黄条显示正在处理你的账户，此时耐心等待第二封邮件通知你！一般处理需要1~6小时左右。

6）补充环节


==========

到上一步已经完成了80%，如果你身处热门区域，比如主区域选的首尔或东京，那还是有概率开不出抢不到机器，也有可能直接被杀头（笑

因此，强烈推荐升级为 Pay-As-You-Go 订阅。升级后不仅可以跨区域开机，而且据玄学统计，PAYG 账户被系统误杀的概率相对较小。但额外要注意的是，跨区域开机产生资源不在免费额度内，请注意查看计费规则！

[

![](https://pbs.twimg.com/media/HEjIHBIbcAAIqvD?format=jpg&name=small)






](/realNyarime/article/2038116106217705668/media/2038098854273576960)

升级教程就很简单了，登录控制台后，顶部黄条警告就直接摊牌告诉你你是 Free Tier 了，直接点击黄条里面的超链接进入 Billing & Cost Managertment 界面。

进入后，在下方的支付方式选项卡右边的三个点点击 Add Payment 按钮，此时依旧是熟悉的 CyberSource 支付，不过这里需要手动补齐你的银行预留手机号（这里不要加入 +86 这种前缀，直接填写手机号即可！

如果卡内余额充足，扣款预授权会顺利通过！这就是前面强调为什么要预留大约140SGD（约760元）等值人民币余额的原因。

![](https://pbs.twimg.com/media/HEjIkpraUAAU6xu?format=jpg&name=900x900)

此时回到主界面后滑倒最顶上，如果你的手机号信息填写无误，IP干净，你会看到你的升级正在处理中，此时就成功了，等邮件吧！
