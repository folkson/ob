昨天晚上在用AI写书单小程序的时候发现了一篇帖子，主要是讲各类AI的主要使用区别的。

给你们分享一下：

一、文字写作类（公众号 / 观点文 / 报告 / 批量内容）  
写观点文、公众号，不易被看出是 AI 写的 → Claude  
英文资料 / 视频 / 图表，整理成中文报告 → Gemini  
大量中文文档、需搜国内资讯梳理 → Kimi  
批量生产、格式标准化内容 → ChatGPT  
快速写中文短内容 → 豆包  
微信生态工作，结合国内热点写内容 → 腾讯元宝  
已有主力工具，想试不同中文写法风格 → DeepSeek / 通义千问

二、语音输入类（减少打字）  
主要在电脑上用语音输入 → 闪电说 / Typeless  
主要在手机上用语音输入 → 豆包输入法

三、图像生成类（人像 / 海报 / 风格图 / 电商素材）  
真实感强的人像、产品图、品牌角色图 → NanoBanana  
带文字的海报、信息图、宣传图、电商配图 → ChatGPT 图像  
风格图、概念图、品牌主视觉、电影感画面 → Midjourney  
中文海报、电商素材、活动配图 → 通义万相  
先做关键帧、角色图、参考图，再接视频生成 → 即梦 AI / 可灵 AI / Runway  
跟着现成风格和社区参考图出效果 → 海艺 AI  
中文环境顺手，从出图到出片全链路 → 即梦 AI

四、视频生成类（真实感 / 数字人 / 特效 / 后期）  
真实感视频，画面 + 声音一起生成 → Google Veo  
生成后还要改镜头、改风格、做后期 → Runway  
快速出片、跨场景转场叙事 → Vidu  
数字人口播、虚拟人讲解、视频翻译、多语言配音 → HeyGen  
特效玩法、照片动起来、传播型创意短视频 → Pika

当然，如果你们只是基础的日常使用，其实豆包就够了。

尤其是你根本没想好自己要做啥或者还没用AI赚到钱的时候，尽量别花冤枉钱。
