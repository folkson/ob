| 冻结Hiview，HiViewTunnel，iAware  
  
Hiview：adb shell pm disable-user com.hihonor.hiview  
  
HiViewTunnel：adb shell pm disable-user com.hihonor.hiviewtunnel  
  
iAware：adb shell pm disable-user com.hihonor.iaware  
  
独限90GT系统数值 132  
具体看：[https://m.bilibili.com/opus/900103146731208726](https://m.bilibili.com/opus/900103146731208726)  
  
卸载Hnaps：adb shell service call package 132 s16 com.hihonor.android.hnaps i32 0 i32 0  
  
卸载HAware：adb shell service call package 132 s16 com.hihonor.powergenie i32 0 i32 0  
  
  
卸载后系统功耗没有负优化，调度没有负优化，续航提升，游戏表现给力。全局120高刷+视频发热抑制正常，冰凉一夏。  
  
另外adb shell service call package ［数值］ s16 ［包名］ i32 0 i32 0  
这个命令可以干掉任何adb权限遮盖的系统进程。 |
